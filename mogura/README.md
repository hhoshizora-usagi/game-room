# モグラたたき — ブラッシュアップ記録

「ほかのゲーム」枠の改善シリーズ、1本目。

## 方針

ルール（30秒・9マス・だんだん速くなる・ベスト記録の保存）は**そのまま**残して、
見た目とアニメーションだけを磨き直しました。
遊び心地・難易度は変えていないので、前と同じ感覚で遊べます。

## 変えたところ

### 見た目

- **モグラをSVGで描き直した** — 絵文字から、耳・鼻・ひげ・前歯・前足まで描いた
  オリジナルのモグラに。画面サイズが変わっても輪郭が崩れません。
- **穴まわりを立体的に** — 奥に暗い穴、手前に土のふち、足もとにゆれる草。
  モグラが穴の奥からのぞいている形が自然になりました。
- **背景を描き込んだ** — 流れる雲、ふわふわ光る太陽、遠くの丘。
  動き続ける背景で、待っている間も退屈しません。
- **金のモグラ** — まれに出る大当たり（+3）。光って見えるので、見つけた瞬間うれしい。

### アニメーション

- **出てくる動き** — バネのように少し行き過ぎてから戻るイージングで、ニュッと出る感触に。
- **たたいた瞬間** — つぶれる → 星が飛び散る → 画面がわずかに揺れる → 「+1」が浮かぶ。
  同じ+1でも、手応えが返ってくるようになりました。
- **コンボ** — 3連続から「COMBO n!」が出ます。続けるほど気持ちよく。
- **スコアの数字** — 加点のたびに弾むように動きます。
- **タイマーバー** — 残り5秒で赤く脈打ちます。
- **結果画面** — パネルが弾むように現れ、スコアが15以上なら紙吹雪が舞います。

### その他

- **音** — Web Audio の簡易SE（ヒット／ミス／金モグラ）。ボタンでミュートできます。
- **動きを控えめに設定している端末** — OSで「動きを減らす」を選んでいると、
  アニメーションを止めて表示だけになります。
- **ベスト記録・ミュート設定は保存されます**（localStorage）。

## 変えていない中身

- 制限時間30秒／3×3の9マス
- 経過時間とともに、出現間隔とモグラの滞在時間が短くなる
- 中盤から2体同時に出ることがある
- 逃すとミス+1
